PICU Handoff 6.89 archive compatibility

Archive schema remains 34. code_status is an optional, validated text field.
Existing archives without this field remain valid. Failed or absent AE in
a complete replacement paste cannot preserve an earlier patient status.

New medication groups are backfilled into older category catalogs during
reads. Requested fixed placements apply without rewriting saved category
definitions. Hidden, excluded and Ignore choices retain their effect.

Original PN and lipid medication rows remain stored. The latest-order
filter changes handoff display only. Dietary scheduling data uses the
existing source field and does not require a schema migration.

Keep existing encrypted archives, passwords, encryption keys and repository
settings. This package does not contain production credentials or uploaded
patient source examples. Prior app versions may reject the new optional
code-status field, so use the updated application files together.
