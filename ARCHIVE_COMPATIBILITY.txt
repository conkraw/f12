PICU Handoff 6.78 archive compatibility

Archive schema remains 34. Encryption and storage format are unchanged.
No key rotation, storage reset, or data migration is performed automatically.
The update adds the import-diagnostic action not_imported. Install all six
changed runtime modules together so the new action can be validated and shown.
A successful import creates a new random handoff ID for the selected room and
replaces that room's complete record. Other rooms and reusable settings remain.
Existing records are not retroactively cleaned or reinterpreted as new patients.
Old encrypted Git history and previously exported files are not erased.

The clinical parsers remain unchanged. Their internal section-composition
helper is no longer the application's user-facing import entry point.
