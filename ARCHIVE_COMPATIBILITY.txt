PICU Handoff 6.79 archive compatibility

Archive schema remains 34. Encryption and storage format are unchanged.
No key rotation, storage reset, or data migration is performed automatically.
The PDF cache is session-private memory only, not a new archive field or a file
stored in GitHub. Old cache entries disappear on reset/logout or app restart.

Install app.py, exports.py, census_guard.py, pdf_cache.py and requirements.txt
together. Reboot/redeploy to install pypdf. Keep existing Streamlit Secrets and
encrypted patient/mapping storage. Do not upload example Secrets over real ones.

The complete-room replacement behavior from 6.78 is retained. A new SmartPhrase
creates a new handoff identity and clears the selected room's previous patient
information. Other rooms and reusable settings are unchanged. Existing saved
records are not retroactively cleaned. Old downloads and printed pages cannot
be recalled. Existing encrypted Git history is not erased.
