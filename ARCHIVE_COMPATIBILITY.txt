PICU Handoff 6.75 archive compatibility

Schema remains 34. There is no data-structure migration or new field.
Existing 6.74 archives load without changing keys, Secrets or passwords.

Existing current_shift snapshots are rendered using the corrected 7am/7pm
schedule. They contain raw normalized volumes, source weight and source time,
not a stored hourly rate. The correction does not require re-pasting.
The bowel_movement boolean is unchanged. Only its rendered label changes.

intake_output, medication mappings and all other stored objects are unchanged.
No values or timestamps are rewritten as part of this presentation/calculation
change. Older downloaded handoff files remain unchanged. Download fresh copies.

Every running deployment that should use the corrected schedule must be updated.
Older applications will continue using their own old calculation code.
