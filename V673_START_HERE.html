PICU Handoff 6.73

Current-shift outputs, separate from your existing 24-hour intake/output summary.

Install

Replace the complete application file set in each app-code repository. Include the new current_shift.py file. Keep app.py at its deployed location. Restart and confirm Version 6.73 | Current Shift outputs.

Keep Streamlit Secrets, the encryption key and encrypted data repositories unchanged. Re-paste a current SmartPhrase to populate the new section.

Example

Current Shift (11pm - 6:30am)
UOP: 2.00 mL/kg/hr
Drains: 0.10 mL/kg/hr
Chest Tube: 0.20 mL/kg/hr
Other: 0.40 mL/kg/hr

Synthetic example. Only supplied output categories appear. No current-shift intake or net balance is shown. Other remains separate from urine.

Calculation

Shifts start at 7am, 3pm and 11pm. Rates use the Weight in the current-shift block and elapsed hours to the source summary timestamp. Last data filed and later print time are not used. Missing or invalid time or weight withholds rates.

The existing 24-hour I/O values, timestamps and behavior are unchanged. Recent nutrition changes remain included.
