PICU Handoff 6.99.1

Fix for the PRN preview error.

Install

PICU Handoff 6.99.1
Baseline: 6.99

Extract PICU6991.zip and open PICU_Handoff_v6_99_1_PRN_Preview_Fix.

If version 6.99 is already installed, replace these files beside the app.py
that Streamlit runs:
app.py
error_store.py
prn_counts.py

Commit the replacements and reboot Streamlit once.
Confirm Version 6.99.1 in the sidebar.
Reopen the handoff and check its saved status.

For version 6.98 or earlier, upload the complete package's application files.
Use the original deployment setup instructions for a new installation.
Keep the existing Streamlit Secrets and encryption key.

This release fixes the PRN preview crash caused by a missing regular-expression
import. Invalid PRN dates that overflow timezone conversion now show a form
validation message and keep the draft instead of crashing the app.

CPAP Trial Data and PRN counting from the most recent 7 a.m. Eastern remain
included. The source-review requirements are described in README.md.

Dependencies and archive schema 34 are unchanged.
Ready to install. No live deployment was performed.
