PICU HANDOFF / VERSION 6.89

Medication categories and code status

The update adds your requested medication groups, imports AE code status into demographics, and displays one latest PN order and one latest IV lipid order.

Install the update

  1. Extract PICU689.zip.
  2. Copy the files inside PICU_Handoff_v6_89_Medications_Code_Status into your existing app repository, beside app.py. Include code_status.py and pn_orders.py.
  3. Restart Streamlit and check the sidebar for Version 6.89.
  4. Re-paste the current SmartPhrase to populate code status for an older saved handoff.

Keep your existing Streamlit Secrets and encryption key.
