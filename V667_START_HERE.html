PICU Handoff 6.67

Separate cuff and arterial pressures. Source-hour intake/output headings.

Install the app files

Replace files in each app-code repository with this folder's contents. Keep app.py at its deployed location and include the new arterial_pressure.py. Restart and confirm Version 6.67.

Keep all existing web-based Streamlit Secrets and the original encryption key. No new Secrets fields are required. Do not replace the encrypted archive in a data repository.

Arterial BP layout

Synthetic example:

Cuff: BP (88-116)/(42-70) 104/54
ART BP: 80/40 to 112/65 [last 108/60]
ART MAP: 52 to 75 mmHg [last 72]

Cuff-only handoffs remain unchanged. Values come from the source. Missing values are not calculated.

Intake/Output window

A 06:00 to 06:59 source summary produces Intake/Output (6a-6a). A 07:10 summary produces Intake/Output (7a-7a). A 18:16 summary produces Intake/Output (6p-6p).

The heading uses the source 24-hour summary timestamp, not Last data filed or the time you reprint an old handoff. Exact minutes remain visible in the editor. Missing or invalid source times keep the generic heading.
