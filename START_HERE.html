PICU HANDOFF / VERSION 6.93

Automatic ventilator import fallback

The app tries the latest-mode history import first. If that fails, it retries the first reported invasive settings from the same new paste.

A successful fallback displays:

Mode history unavailable. Showing first reported settings from this paste. Latest mode unconfirmed.

This note stays in the saved handoff, Alerts and printed output. Conflicting or unusable first settings still produce an import warning.

Install from 6.92

Extract PICU693.zip. Copy all six files below from PICU_Handoff_v6_93_Vent_Fallback into the existing app folder:

app.py
ventilation.py
noninvasive.py
importing.py
workspace_ui.py
error_store.py

Reboot Streamlit and confirm Version 6.93. The fallback applies automatically to new imports.

For an earlier app version, use the complete package contents. Keep your existing Streamlit Secrets and encryption key.
