PICU HANDOFF / VERSION 6.98

Print timer and one-page fitting

Print all now shows a live elapsed timer and counts prepared handoffs. Click Prepare selected handoffs, wait for Ready to download, then download the PDF.

Choose Auto-fit to 1 page. When needed, the print layout uses compact medication and device text and omits Goals / Follow-up. Saved notes remain intact. Exceptionally long clinical content continues onto another page and is reported.

Install from 6.97

Extract PICU698.zip and open PICU_Handoff_v6_98_Print_Timer_One_Page. Replace the existing files below and add print_feedback.py:

app.py
error_store.py
exports.py
pdf_cache.py
print_feedback.py

Reboot Streamlit once and confirm Version 6.98.

For an earlier version, use the complete package contents. Keep your existing Streamlit Secrets and encryption key.
