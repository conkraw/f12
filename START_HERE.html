Install from 6.91

Extract PICU692.zip. Copy app.py, ventilation.py and error_store.py from PICU_Handoff_v6_92_Compact_Vent_Modes into the existing app folder.

Reboot Streamlit, confirm Version 6.92, then open the handoff and prepare a fresh print or download. Existing handoffs with mode-history dates do not need a new import for this display update.

For an earlier app version, use the complete package contents. Keep your existing Streamlit Secrets and encryption key.
