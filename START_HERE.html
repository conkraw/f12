PICU Handoff 6.76

Two clear choices after login

Create New Handoff for Rounds/Signout

Clears all saved handoffs and this session's open drafts, then opens an empty patient list. Add your patients for rounds or signout.

The clearing message appears before you click. The button applies immediately, without another review or confirmation screen.

Print, Update, or Add to Current List

Keeps all current patients. Print the list, update existing handoffs, or add new patients.

Both choices work at any time. There is no morning window or once-per-day restriction. You can start another blank list when you log in later the same day.

Install

For an update from version 6.75, replace both app.py and daily_start.py in your existing app-code repository. Replace both files together, or replace the complete application file set. Use the full set when updating from an earlier version.

Keep Streamlit Secrets, your encryption key, and separate encrypted patient-data and mapping repositories. No new dependency is required.

Restart the app and verify Version 6.76 | Clear start options in the sidebar.

Existing settings and clinical features

Reusable settings, medication mappings, and custom room definitions are preserved. Nutrition, 24-hour I/O, 7am/7pm current shifts, the compact BM label, and other clinical parsing remain as they were in version 6.75.
