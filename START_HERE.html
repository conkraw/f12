PICU HANDOFF / VERSION 6.90

Latest ventilator mode first

The handoff compares the timestamps in All Vent Modes, shows the latest reported mode first, and lists the other distinct modes with their matching reported settings.

Install the update

  1. Extract PICU690.zip.
  2. Copy the files inside PICU_Handoff_v6_90_Vent_Mode_History into your existing app repository, beside app.py.
  3. For an app already on 6.89, replace app.py, ventilation.py, noninvasive.py and error_store.py.
  4. Restart Streamlit and check the sidebar for Version 6.90. Re-paste the complete SmartPhrase including All Vent Modes.

Keep your existing Streamlit Secrets and encryption key.
