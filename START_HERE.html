PICU Handoff 6.66

Mapping Sync diagnostics, Probiotic and ADH Analog display groups.

Install the app files

Replace the files in each app-code repository with this folder's contents. Keep app.py at its deployed location. Restart and confirm Version 6.66.

Keep all existing web-based Streamlit Secrets and the original encryption key. No new Secrets fields are required. Do not replace the encrypted archive in a data repository.

Find the Mapping Sync issue

Open Admin > Mapping Sync > Check connections (read only).

Each app shows its result. Expand Action needed to see the failed step, code, HTTP status and suggested correction. Use Copy diagnostic report or Download diagnostic report to capture the results without relying on deployment logs.

The check does not write mappings, backups or patient data. A successful read does not prove write permission.

Desmopressin and DDAVP: Neurology (the existing Neurologic section) > ADH Analog.

Source doses, routes and frequencies stay unchanged. Existing explicit category/group overrides and hidden orders are retained.
