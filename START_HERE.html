PICU Handoff 6.56

Difficult-airway choices

Updating a handoff with existing difficult-airway details now asks whether to keep or delete them. Cancel leaves the handoff unchanged. Save handoff or change rooms after making your choice.

Under Room actions, Delete all handoff data offers full deletion and a second option that clears other patient data while keeping difficult-airway details in their original rooms. Custom rooms remain only when they contain retained airway details.

Both reset options work without an Admin password. Confirm that retained details belong to the current patient before keeping them on a new import.

Install

Replace the application files with this folder's contents. Keep app.py at the root, restart the app, and refresh your browser.

Only app.py, difficult_airway.py, and handoff_reset.py changed among application code files.

Keep existing Secrets, passwords, encryption key, mappings, categories and reference data unchanged. Do not rerun setup generators. No new dependencies or re-pasting are required.

Settings remain intact after either reset. Other team members should reload the saved archive. Earlier archive versions and downloaded copies are not erased.
