PICU Handoff 6.69

AVAPS settings in Respiratory, with the QTc, NIRS and override-pull medication changes from 6.68 included.

Install

Replace the application files in each app-code repository. Keep app.py at its deployed location. If an app already runs 6.68, copy app.py and ventilation.py together. Restart and confirm Version 6.69.

Keep your existing Streamlit Secrets, encryption key and separate data repositories. Re-paste the updated SmartPhrase to populate the AVAPS settings.

QTc, NIRS and medications

The newest dated Bazett QTc supplied is eligible without an age limit. Above 450, the QTc line is red with (!) and Long QTc appears in Problems.

NIRS appears in Neuro when available, with its recorded minimum, maximum and latest value. Override-pull medications default to Ignore. You can restore an entry from Ignored / hidden medications.

Values on this page are synthetic examples.
