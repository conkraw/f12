PICU Handoff 6.77

START HERE: Create an Updated Handoff

Choose this when preparing a new patient list for rounds or evening handoff. The button opens a warning and does not delete anything.

The warning states that ALL previous handoffs will be deleted from the current list. All saved handoffs and this session's open drafts will be removed, leaving a blank patient list.

Choose Move Forward and Delete Previous Handoffs to confirm. You can then add the patients for your new handoff.

If the saved list changes while the warning is open, confirmation reloads the current list and shows the warning again without deleting anything. Review it and click the confirmation button again to proceed.

Add a Patient or Print Current List

Choose this if you only want to add a patient or print the existing list. This option appears on both the opening screen and the warning screen. It keeps all current handoffs.

Both workflows work at any time. There is no morning window or once-per-day restriction. You can start another updated handoff when you log in later the same day.

Install

Use your existing app-code repository. From version 6.76, replace app.py. If updating from version 6.75, replace both app.py and daily_start.py together.

For an earlier version, replace the complete application file set. The complete file set can also be used for any update.

Keep Streamlit Secrets, your encryption key, and separate encrypted patient-data and mapping repositories. No new dependency is required.

Restart the app and verify Version 6.77 | Start here + confirmation in the sidebar.

Existing settings and clinical features

Reusable settings, medication mappings, and custom room definitions are preserved. Nutrition, 24-hour I/O, 7am/7pm current shifts, the compact BM label, and other clinical parsing retain their existing behavior.
