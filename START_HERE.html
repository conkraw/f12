PICU Handoff 6.78

Replace room handoff

Select the correct room and paste the complete new SmartPhrase. Replace room handoff builds and saves a new handoff for that room only. Previous patient data, omitted fields, manual notes, and airway information are cleared. Other rooms and reusable settings stay unchanged. This also applies when updating the same patient.

Failed imports

A completely unusable paste does not replace the old handoff. An unconfirmed save does not claim success. Correct the paste or reload the archive before retrying. A partly successful import uses only new information and flags failed sections. Review Alerts before use.

Your existing start buttons

START HERE: Create an Updated Handoff still opens the clear-all warning. Move Forward and Delete Previous Handoffs confirms the reset. Add a Patient or Print Current List keeps the list. A new import in either workflow replaces only its selected room.

Install

Replace all six changed modules together: app.py, importing.py, import_review.py, census_guard.py, user_guide.py, workspace_ui.py. The full file set can also be uploaded. Keep Secrets, the encryption key, and separate storage repositories. Restart and verify Version 6.78 | Replace, never merge.

Before clinical use

Verify with two fictional patients in the same room, including an old manual note and omitted fields. Confirm the second patient fully replaces the first in saved data and print output while another room stays unchanged. Use START HERE to rebuild any existing list that might already contain mixed information.

Limitations

No live app, clinical data, or production repository was accessed. Existing saved records are not retroactively corrected. Encrypted Git history, previously downloaded files, and printed pages are not erased. Other users must reload their open previews. See TEST_REPORT.md for test results and scope.
