PICU HANDOFF / VERSION 6.91

Verify the respiratory update

The app now checks that the loaded respiratory importer handles All Vent Modes before importing a patient.

Install

  1. Extract PICU691.zip and open PICU_Handoff_v6_91_Respiratory_Import_Check.
  2. Replace app.py, ventilation.py, noninvasive.py and error_store.py in the existing app folder.
  3. Reboot Streamlit. Confirm Version 6.91 and Respiratory mode-history parser: ready in the sidebar.
  4. Re-paste the complete current SmartPhrase.

Put the files beside the app.py that Streamlit runs. Keep the existing Streamlit Secrets and encryption key.

What caused the reported error?

The older parser reproduces the exact repeated-field error. Both new examples import respiratory support with the bundled parser. The loaded-parser check makes an incomplete update visible before a handoff is replaced.
